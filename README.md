# Atividade Prática - Sábado Letivo (Desenvolvimento Mobile)

Este é o meu projeto do aplicativo de Gestão de Tarefas feito em Flutter. 

## O que o app faz:
* Dá para adicionar tarefas com título e descrição.
* Lista as tarefas e dá para marcar como concluída.

## Requisito Extra
Para cumprir a exigência de adicionar funcionalidades extras, implementei:
1. **Contador de tarefas:** Mostra no topo (AppBar) o total de tarefas que estão na lista.

## Como executar o projeto
Para testar o código no teu computador, segue estes passos:

1. Faz o clone deste repositório:
   ```bash
   git clone https://github.com/bochches/Programacao_mobile.git

2. Para rodar o app do emulador pressione a tecla F5 ou, caso prefira na web, abra o terminal e digite flutter run.
